# Frozen study data

These are data underlying the manuscript, not a mirror of all Polymarket trades. The event taxonomy, volume summaries, graph degree counts and within-paper account identifiers are study derivatives. Titles, contract identifiers and leaderboard records originate from Polymarket. Source checksums describe the historical files actually used; a live API query is not an exact substitute for the frozen snapshot.

| File or directory | Contents and unit of observation |
|---|---|
| `gamma/event_subjects_v3.parquet` | All 931,023 metadata event IDs, including events not observed in fills. One row per event: title, slug (the URL identifier), normalized platform tags, one of 21 subject IDs, subject name, basis of classification and frozen taxonomy version. Subject labels are the authors’ rule output, not labels supplied by Polymarket. |
| `gamma/condition_map/part-*.parquet` | Canonical bridge from a market condition to its event: 2,946,628 rows. A condition ID is stored as 32 raw bytes; recover the conventional text with `"0x" + value.hex()`. Market and event IDs are integers here; the event dictionary uses decimal strings. The source had 2,948,008 market records; 1,380 had no condition ID. |
| `gamma/tags.jsonl.gz` | Original frozen dictionary of 6,899 tags (ID, label, slug). |
| `gamma/presidential_election_2024_conditions.json` | The 17 Gamma market records in the focal election event, with market and condition IDs, question, slug, outcome labels and ordered token IDs where available. These are contract identifiers, not wallet addresses. |
| `leaderboard/observed_pages.csv.gz` | Numeric projection of the two archived calls used in the paper: OVERALL, ALL, ordered by VOL or PNL. Contains order, page offset, returned rank and both API-reported amounts; 21 successful pages of 50 ranks per ordering (2,100 rows). The API pagination ceiling was reached; this is not a census. |
| `leaderboard/overall_all_top1000.csv` | The exact two 1,000-rank study inputs. Numeric values follow the frozen study CSV; per-rank differences from the API-page serialization are below 0.000001. The two lists contain 1,598 distinct ranked accounts, with 402 in both. A snapshot-only ID links repeated accounts without including addresses or profile fields. Rank and public amounts may still permit external matching. |
| `study/mapped_event_totals.parquet` | One row per observed mapped event (764,378): event ID, number of **observed** constituent conditions, number of executed fills and executed USDC volume. Omits 596 unmapped condition-key rows in the upstream aggregation. Event volume is fill-based, not the Gamma API’s separate reported-volume field. |
| `study/wallet_amounts/part-*.parquet` | All 3,106,517 positive wallet participation amounts (USDC), sorted in ascending order across both parts. No addresses, account IDs, or source ordering. This is the **full archive concentration frame**, including participation not mapped to an event; it is not the network’s wallet population. Gini reproduced from these amounts: 0.9623243404979405. |
| `study/bipartite_degree_counts.csv` | For each node partition and each distinct positive degree, the exact number of nodes at that degree in the complete mapped graph. The event and wallet frequencies sum to 764,378 and 3,106,514 nodes, respectively. Each partition’s degree sum is 255,704,359 wallet–event pairs. These frequencies are sufficient for marginal degree-tail fits, not for identifying nodes or recovering the network topology. |
| `study/*.json`, `study/*concentration.csv`, `study/taxonomy_transitions_*.csv` | Processing provenance, aggregate concentration checks and v2-to-v3 taxonomy changes. The full-frame assignment is v3. Regression checks are not an independent human validation. |
| `Source_Data/Fig1_concentration` through `Fig6_8_election` | Compact original numerical inputs and plot coordinates for manuscript visuals. Historical folder numbers are retained for script compatibility; they are not instructions to include old figures. Atlas coordinates are those from the corrected version. Election data provide subject vectors for 971 October-active and 1,630 eligible wallets from the four extreme purchase cohorts, with no public addresses or identity linkage. See their two metadata files for inclusion, units, subject columns and de-identification. |
| `Source_Data/Supplementary` | Frozen power-law fits, cutoffs and alternative-model comparisons; historical workstation paths have been reduced to source filenames without altering numerical results. |

### Where the data came from

- Polymarket Gamma API, collected **1 September 2026, 11:40:20–12:54:17 UTC**: <https://gamma-api.polymarket.com>. `gamma/retrieval_manifest.json` records original file hashes, row counts and retrieval information; all three original hashes were checked. `gamma/derived_provenance.json` records hashes for the upstream derived dictionary, event totals and clean condition map. The event and condition files here are column projections, not the original compressed responses. Events omit dates, state flags and Gamma-reported volume/liquidity, which are unnecessary for these outputs; the condition map omits questions, dates, token lists and flags outside the focal election.
- Polymarket Data API, collector run **4 September 2026, 08:21:52–08:30:05 UTC**: <https://data-api.polymarket.com/v1/leaderboard>. See `leaderboard/provenance.json` for query-level raw JSON hashes and page-level retrieval times. The full collection covered 88 combinations of category, period and ordering; only the two used here are distributed. The original HTTP headers, public profile payloads, display names, social accounts, wallet addresses and the other 86 queries are not distributed.
- Executed fills are sourced separately from **TimeSeventeen/Polymarket-v1**, revision `5aa1b9d52316a8b2e789e81c8ae42c7ed532e8aa`, and **TimeSeventeen/Polymarket-v2**, revision `2a8dba6472f4c9ca558869e9cc1a65b9e1614264`, on Hugging Face. The raw fill shards and the full wallet–event edge list are not redistributed. Degree counts and community quotient weights reproduce corresponding summaries; they do not replace the full graph for re-detecting communities. Ranked PNL is the platform’s reported field, not a reconstruction of realized gains for all wallets.

The Polymarket metadata and rankings remain third-party source material. This deposit does not assign a new license to upstream data or imply that a software license covers them. Review the upstream terms and attribution obligations before public redistribution.
